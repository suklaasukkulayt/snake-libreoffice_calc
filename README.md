# Snake in LibreOffice Calc  

## Info  
This is the classic Snake game in [LibreOffice Calc](https://www.libreoffice.org/download/) (Excel but open-source and free).  
This is made for the Wrong Tool Hack Club event.  
See my Lapse timelapses for development info.  

## How to make it work  
### For this to work at all, you have to allow macros like so:  
1. Open any document in LibreOffice Calc (if it's this one you might need to restart after this)  
2. Go to Tools -> Options (or just press Alt+F12 (atleast on Windows)  
3. Go to LibreOffice -> Security -> Macro Security  
4. Set it atleast to Medium (low not recommended) and every time you open this, press Enable macros.  

### For the on-screen buttons to work, make sure you have Design Mode disabled:  
1. Go to View -> Toolbars -> Form Controls  
2. There find the second icon from the left on the first row, that says "Design mode" when hovering over it and click that so it's **not** selected  
3. Then you can close Form Controls.  

## How to play  
The game is in Sheet 2, ”Snake Game”  
Default speed is 150  
Press start, or enable arrow key control and press enter to start the game.  
You win if you get 400 points. You can also see how many wins you have.  
You can see your score and your high score.  
(Save the document after playing to save your high score)  
Eat the apples to grow your snake. (Red cells are apples, the lighter green is your snake. The light green cell with no borders is your head.)  
If you hit a wall or try to eat yourself, you die.  
When you die, your score shows in the game over box.  

### Controls:  
| Button | Action |
| --- | --- |
| Arrow keys: | Move |
| Enter: | Start |  


Also, the ”Stop arrow key control” might not always work properly, sorry about that.
